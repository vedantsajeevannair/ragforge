# BM25

BM25 is a lexical ranking function used by search engines to score how relevant a document is to a query.

## How the score works
For each query term, BM25 multiplies the inverse document frequency (IDF) of the term by a saturated term frequency. Rare terms get a high IDF, so matching them counts for more than matching common words.

## Parameters
The parameter k1 controls term-frequency saturation: after a few occurrences, extra repeats add little. The parameter b controls length normalisation, so long documents are not favoured just because they contain more words. Typical defaults are k1 = 1.5 and b = 0.75.

## Strengths and weaknesses
BM25 is fast, needs no training and is excellent at exact matches such as product codes, names and rare jargon. It fails when the query and the document use different words for the same idea, because it has no notion of synonyms.
